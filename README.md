# 우리 교실

여러 사람이 같은 3D 초등학교 교실에 들어와 함께 머무는 웹 서비스입니다.

## 실행

```
npm install
npm start
```

브라우저에서 http://localhost:3000 을 엽니다. 포트는 `PORT` 환경변수로 바꿀 수 있습니다.

## 조작

- 바닥 클릭 또는 WASD/방향키: 걷기
- 드래그: 둘러보기, 휠이나 두 손가락: 확대/축소
- 점프 버튼 또는 스페이스 키: 점프
- 책상이나 의자 클릭: 앉기, 아래 메뉴의 앉기 버튼: 가장 가까운 빈자리에 앉기 / 일어서기

- 자습하기 버튼: 빈자리에 앉아 구구단이나 나머지 없는 나눗셈 10문제 풀기 (점수는 내 화면에만 보입니다)

## 구조

- `server.js`: 정적 파일과 WebSocket 서버. 접속 상태는 메모리에만 둡니다.
- `public/js/main.js`: 입력, 카메라, 네트워크, 화면 UI
- `public/js/world.js`: 교실과 창밖 풍경
- `public/js/avatar.js`: 아바타와 동작
- `public/js/data.js`: 방 정원, 닉네임 단어, 말풍선 문장
- 교실 운영: 선생님이 첫 화면에서 '우리 반 교실 만들기'를 누르면 서버가 4자리 방 코드를 정하고 교실을 엽니다. 학생은 같은 코드를 입력하거나 교실 안 왼쪽 위 방 코드 버튼의 QR 코드를 찍어 들어옵니다. 같은 코드끼리만 한 교실에서 만나고(최대 25명), 3시간 넘게 비어 있으면 교실이 닫힙니다.
- 글꼴: Pretendard (`public/fonts`, SIL Open Font License)
- 이용자 수: GoatCounter(`minfp-online-classroom`)로 세고 왼쪽 위에 오늘/전체를 표시합니다. 숫자는 최대 4시간 늦을 수 있습니다.
- `public/js/schedule.js`: 모두 같은 시계로 도는 40분 수업 + 10분 쉬는 시간 (주소에 `?demo=1`을 붙이면 40초 + 10초)

서버 없이 정적 호스팅에 올리면 혼자 모드(나만 있는 교실)로 동작하고, 교실 만들기와 교사 기능은 쓸 수 없습니다.

## 안전 기본값

친구들 화면에 보이는 이름은 랜덤 동물 이름이고, 말풍선은 정해진 목록의 번호만 주고받습니다. 칠판은 소품이라 글이나 그림을 쓸 수 없습니다. 학생이 자유롭게 쓴 글이 다른 학생 화면에 나올 길은 없습니다.

예외는 두 가지이고 모두 선생님에게만 보입니다.

- 학생이 입장할 때 적는 진짜 이름(글자·숫자·띄어쓰기 10자까지)은 서버가 선생님에게만 전달합니다. 친구들에게 가는 데이터에는 들어 있지 않습니다. 이름은 서버 메모리에만 있고 교실이 닫히면 사라집니다. 공용 기기에 남지 않게 브라우저 탭을 닫으면 잊힙니다.
- 선생님이 낸 문제 글은 학생 화면에 그대로 나옵니다. 문제는 선생님만 보낼 수 있습니다.

## 교사 기능

교실을 만든 선생님(만든 기기·브라우저)만 쓸 수 있습니다. 서버가 교실을 만들 때 정해 준 비밀 값(토큰)을 선생님 브라우저가 저장해 두었다가 입장할 때 보내는 방식이고, 학생에게는 이 값이 가지 않습니다. 선생님은 이름표가 "선생님"으로 보입니다.

- 모두 앉히기·문제 내기를 하면 "수업 중" 상태가 되어 학생은 종이비행기를 날릴 수 없습니다(서버도 막습니다). "자유롭게 하기"로 풀 수 있고 선생님은 늘 날릴 수 있습니다.
- 모두 앉히기: 서 있는 학생을 서버가 정한 빈 자리에 앉히고, 학생 화면에 "앉아야 합니다!"가 (고른 언어 번역과 함께) 뜹니다.
- 공부하기: 선생님이 문제와 정답을 적어 보내면 학생 화면에 문제 창이 열립니다. 정답은 서버에만 있고 채점도 서버가 합니다. 나중에 들어온 학생에게도 진행 중인 문제가 뜹니다. 문제는 번역되지 않고 쓴 그대로 보입니다.
- 결과 보기: 학생 이름별로 문제마다 O/X와 맞힌 개수가 실시간으로 나옵니다. 한 문제는 처음 낸 답만 점수에 들어가고, 학생이 나가도 결과는 남습니다. 같은 이름의 학생이 둘이면 한 사람으로 합쳐 보입니다.
